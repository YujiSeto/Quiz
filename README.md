# 🎯 Quiz

## 📌 Description
This is an **interactive quiz** built with HTML, CSS, and JavaScript, featuring a dynamic progress bar, animated feedback, and a clean, responsive design.  
Its goal is to test users’ knowledge in a fun, intuitive way.

---

## 🚀 Features
- **Animated progress bar** showing quiz completion in real time  
- Dynamic display of **questions and answer options**  
- **Final score area** with:
  - Percentage of correct answers  
  - Number of questions answered and correct answers  
  - Motivational message and prize image  
- **"Play Again"** button to restart the quiz  
- Responsive layout and stylish UI

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
